# Відповідність технічному завданню

**Проєкт:** лендінг оренди автобусів і мікроавтобусів + адмін-панель
**Дата перевірки:** 2026-09-22
**Де перевірено:** локальний PostgreSQL **і** реальна зовнішня база Neon (не на нашому сервері)
**Результат наскрізних тестів:** `npm run test:e2e` → **64/64** на обох базах
**Автоматичний аудит пунктів ТЗ:** 23/23 PASS (секції, поля, адаптивність, предзаповнення форми)

---

## 1. Структура сайту

| Пункт ТЗ | Реалізація | Доказ |
|---|---|---|

## 4. Блок «Про компанію»

Редагуються: назва компанії, текст, роки роботи, кількість автобусів, кількість поїздок, кількість клієнтів, підписи показників, фото блоку.
На сайті відображаються 4 показники: `12+ / 40+ / 25000+ / 1800+` (перевірено).

## 5. Блок «Наш транспорт» — картка

Усі 9 обов'язкових елементів присутні (перевірено автоматично):
фотографія · назва · марка/модель (+ рік) · кількість місць · тип транспорту · короткий опис · ціна · умови оренди · кнопка «Замовити».

## 8. Ціни

Ціна зберігається окремо для кожного транспортного засобу, з одиницею розрахунку
(година / день / поїздка / км). Зміна в адмінці **одразу** відображається на сайті
(сторінка рендериться на сервері при кожному запиті — перевірено: 80 € → 99 € → 80 €).

## 9. Послуги · Переваги · Кроки

- **Послуги**: назва, іконка або фото, опис; додавання/редагування/приховування/видалення; кількість не обмежена.
- **Чому обирають нас**: перелік переваг, **кількість редагується** (додавання/видалення/порядок).
- **Як відбувається замовлення**: кроки з автонумерацією; 3–4+ кроки, повністю редаговані.

## 11. Додаткові вимоги замовника

| Вимога | Реалізація |
|---|---|
| **БД не на нашому сервері, безкоштовно** | PostgreSQL-сумісна зовнішня база: **Neon** (перевірено на реальному віддаленому інстансі), також підтримуються Supabase і Vercel Postgres. Схема, стартовий контент і адміністратор створюються самі при першому запиті |
| **Адмінка з ktk-landing** | Взято з `github.com/dmytropshenichnikov/ktk-landing` (клоновано через SSH) і адаптовано: та сама схема «один універсальний CRUD API + токен-авторизація», розширена під ТЗ |
| **Універсальні можливості створення й редагування** | Розділ **«Конструктор блоків»**: створення власних типів контенту з довільними полями (текст, багаторядковий текст, число, зображення, список, так/ні) і необмеженою кількістю елементів; кожен активний блок автоматично стає секцією на сайті |
| **Перевірити GitHub Пшеничникова через SSH** | Виконано: знайдено `dmytropshenichnikov/ktk-landing` (використано як основу адмінки) і `tesla-parts` (вивчено як референс архітектури) |

## Як перевірити самостійно

```bash
npm install
npm run build && npm start          # http://localhost:3000

npm test                            # 20 юніт-тестів
npm run test:e2e                    # 64 наскрізні перевірки
```

Адмінка: `/adminpanel/login` — усе, що є в ТЗ, редагується саме тут:
автобуси, фото з підписами, ціни, послуги, переваги, кроки, форма, контакти,
логотип, SEO, додаткові блоки (конструктор), адміністратори Telegram-бота.
