## Зовнішня БД — перевірено на реальному віддаленому Postgres
Створено справжню віддалену базу **Neon** (`ep-damp-queen-b5edpemf-pooler.c-7.us-east-2.aws.neon.tech`,
`sslmode=require`) — не на нашому сервері, безкоштовно. Перевірено проти неї:
- автостворення 11 таблиць + сидинг (8 автобусів / 6 послуг / 8 переваг / 4 кроки / FAQ + 3 елементи / 54 налаштування / адмін);
- вхід в адмінку, CRUD автобусів, конструктор блоків, завантаження фото → `media` у зовнішній БД,
  віддача через `/api/media/:id`, прийом заявок;
- дані зберігаються після перезапуску застосунку;
- **Playwright E2E 39/39 проти зовнішньої БД**.
Рядок підключення — у `.env.neon` (файл у `.gitignore`). База тимчасова (72 год),
її можна залишити назавжди через claim-посилання, або створити власний проєкт на neon.tech.
